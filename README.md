\# 🛡️ ScamShield – Scam Message Detector



\## 📌 About the Project



ScamShield is a simple AI-based scam message detection system.



It analyzes a user's message and identifies whether the message is:



\- 🚨 Scam

\- ✅ Safe



The system checks suspicious words and provides a risk level.



\## 🎯 Features



\- Scam message detection

\- Safe message detection

\- Risk level prediction

\- Simple and user-friendly interface

\- Fast results



\## 🛠️ Technologies Used



\- Python

\- Pandas

\- Scikit-learn

\- Streamlit

\- Machine Learning
